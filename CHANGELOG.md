# Changelog

## 1.0 — 2026-11-06
First release.
- Overleaf-style editor: code and visual modes, completion for commands, `\cite` keys and `\label`s, find/replace, tabs, file explorer.
- Local compile with latexmk (engine from `% !TEX program = …`), compile log with the first error, Stop.
- PDF viewer with text selection, search, zoom, SyncTeX both ways.
- Open a `.tex` file, a folder or an Overleaf `.zip` through the system file chooser; import a `.zip` into a project from the explorer; download a project as a zip.
- macOS app (`scripts/install-app.sh`), localhost-only server, confined file access.
